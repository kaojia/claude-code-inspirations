# Claude Code 專案靈感集

一份每日更新的 Claude Code 專案靈感集，涵蓋初階 / 中階 / 高階三種難度，並附上「起手式提示詞」可直接複製使用。

## 線上瀏覽

啟用 GitHub Pages 後，可在以下網址瀏覽：

```
https://<你的-github-帳號>.github.io/claude-code-inspirations/
```

## 內容分類

- **初階**：適合 Claude Code 新手的入門專案
- **中階**：開始使用 Skill、Subagent 等進階功能
- **高階**：多 Agent 協作、自動化系統等深度玩法

## 主題類別

生產力 · 內容創作 · 資料分析 · 程式原型

## 功能

- 即時搜尋（支援標題、描述、隱藏關鍵字）
- 分類標籤一鍵篩選
- 每日新增 + 歷史收錄分區
