會議逐字稿摘要精靈

把冗長的會議錄音逐字稿變成結構化的行動清單與決策紀錄

將 Zoom、Teams 或 Google Meet 匯出的會議逐字稿丟給 Claude Code，自動產出三份文件：一頁式會議摘要、按負責人分類的行動項目清單（含截止日）、以及需要追蹤的未決議題表。特別適合 PM、主管、或每天開不完會的上班族，再也不用手動整理會議紀錄。

這是我們今天的會議逐字稿 [貼上或拖曳檔案]。請幫我做以下處理：1. 產出一份 500 字以內的會議摘要，包含主題、與會者、關鍵討論點 2. 列出所有行動項目，格式為表格：負責人 / 待辦事項 / 截止日期 / 優先級（高中低）3. 整理出所有尚未做出結論的未決議題 4. 輸出成 meeting_summary.md 和 action_items.csv 兩個檔案 5. 如果逐字稿中有模糊的時間描述如『下週』，請換算成實際日期
為什麼是好的初階專案 練習 Claude 的文本摘要與資訊擷取能力，輸出格式簡單，新手立刻能在工作中使用

競品功能差異分析器

輸入多個競品網址或文件，自動產出視覺化的功能比較矩陣與策略建議

給 Claude Code 你的產品規格書與 2-5 個競品的公開資料（官網截圖、定價頁、功能清單），它會自動建立互動式 HTML 功能比較矩陣、計算功能覆蓋率雷達圖、找出你的產品缺口與差異化優勢，最後產出一份可直接放進簡報的競品分析報告。適合產品經理、行銷團隊、創業者在做市場研究時使用。

我要做競品分析。以下是資料： - 我的產品功能清單：[貼上或拖曳檔案] - 競品 A 資訊：[貼上網址或截圖] - 競品 B 資訊：[貼上網址或截圖] - 競品 C 資訊：[貼上網址或截圖] 請幫我：1. 建立資料夾結構 competitor_analysis/，包含 index.html 主頁面 2. 產出互動式功能比較表，支援篩選與排序，用綠色勾/紅色叉標示 3. 用 Chart.js 畫出各產品的功能覆蓋率雷達圖 4. 分析我的產品在哪些維度領先、哪些落後 5. 給出 3-5 條具體的產品策略建議 6. 整份報告要能直接用瀏覽器開啟，風格專業簡潔

多語系文案工作流引擎

建立一套完整的 i18n 內容管線，從文案撰寫、翻譯、語氣校正到部署格式輸出

打造一個端對端的多語系內容生產系統：輸入產品功能描述或行銷需求，Claude Code 會依照品牌語氣指南產出中文主文案，接著自動翻譯成英文、日文、韓文等目標語言，針對每種語言做文化在地化調整（不只是直翻），產出 JSON i18n 檔案、各語系的 SEO meta 標籤、以及一份翻譯品質自檢報告。整套系統包含 Node.js CLI 工具，可整合進 CI/CD 流程，適合有多國市場的產品團隊與獨立開發者。

請幫我建立一個多語系文案工作流工具，專案名稱 i18n-content-engine/，結構如下： 1. 建立 CLI 入口 cli.js，支援指令：generate（產文案）、translate（翻譯）、validate（檢查）、export（輸出） 2. 讀取 config/brand-voice.yaml 品牌語氣設定檔（請產生範本，包含語氣關鍵字、禁用詞、各語系注意事項） 3. generate 指令：輸入功能描述，依品牌語氣產出 zh-TW 主文案，包含標題、副標、CTA、功能說明段落 4. translate 指令：將主文案翻譯至 en、ja、ko，每種語言要做文化適配（如日文敬語層級、韓文語尾處理），不能是機械直翻 5. validate 指令：自動檢查各語系字數限制、placeholder 變數一致性、是否有未翻譯殘留、敏感詞篩查 6. export 指令：輸出 locales/[lang].json（i18n 標準格式）、seo-meta.csv、translation-report.md（含各語系品質分數與改善建議） 7. 加上 package.json 與完整 README.md，包含安裝步驟與使用範例 8. 請為核心函式寫單元測試放在 tests/ 資料夾
為什麼是好的高階專案 整合 CLI 架構設計、多語系 NLP 處理、YAML/JSON 配置管理與測試撰寫，是真正可投入生產的開發級專案

個人知識閃卡產生器

把任何文章/PDF 丟進去，自動產出可印或匯入 Anki 的學習卡片

給 Claude Code 一份 PDF、教科書章節、會議簡報，請它幫你抽出核心概念，產出「正面問題／背面答案」的閃卡，並輸出成 CSV（可匯入 Anki）+ 可印的 PDF 兩種格式。準備證照考試、學新領域、做讀書會的人特別好用。

這份 PDF [拖曳檔案] 是我要學的內容。 請幫我： 1. 抽出 20 個最值得記住的概念（不要太瑣碎） 2. 每個概念做成一張閃卡： - 正面：一個問題（不是「什麼是 X」這種問法，要刺激思考） - 背面：精簡答案 + 1 個記憶口訣或聯想 3. 輸出兩個檔案： - flashcards.csv（Anki 匯入格式） - flashcards.pdf（適合列印，一張 A4 印 6 張卡）
為什麼是好的初階專案 讓你親身體驗 Claude「閱讀理解 +整理輸出」的能力，而且做完馬上能用在自己的學習上——這是養成「用 AI 解決真實問題」習慣的關鍵第一步。

Email 處理 Skill 系統

用自然語言寫一份「我的 Email 規則」，Claude 幫你分類、寫草稿、整理收件匣

建立一個 Claude Code Skill（其實就是一份 markdown 規則文件），描述你怎麼處理信件：「老闆寄的優先回 / 訂閱信整理成週報 / 廠商詢價自動產生報價草稿」。之後每次跑 `/email` 指令，Claude 就會按你的規則處理。比 Gmail 的篩選器更靈活，因為它能「讀懂內容」而不只是看寄件人。

幫我建立一個 .claude/skills/email-handler/SKILL.md 我要 Claude 在我下 /email 指令時，依以下規則處理收件匣： 【優先處理】 - 老闆（boss@company.com）的信：摘要重點、產生回覆草稿 - 客戶詢價：產生報價草稿（參考 /templates/quote.md） 【整理歸檔】 - 訂閱電子報：摘要成「本週重點 5 條」，存到 newsletters/2026-W21.md - 系統通知信：直接歸檔，不需提醒我 【需要我決定】 - 會議邀請：列出與我行事曆衝突的，請我裁決 請先建立 SKILL.md，再示範跑一次。
中階關鍵概念：Skill Skill 就是「教 Claude 一個你的習慣」——寫一次規則，之後永久重複使用。比逐次下指令更省力、品質更穩定，這是 Claude Code 進階使用者的核心技能。

8 高階 多 Agent 3-5 小時 5/17

客製化 Subagent 編輯團隊

打造 4 位專業 AI 同事：研究員、編輯、校對、排版——讓他們互相協作

進階用法：建立 4 個 Claude Code Subagent，每個都有自己的系統提示詞、專屬工具權限、獨立記憶。當你說「幫我寫一篇關於 X 的文章」，主 Claude 會自動分派任務：研究員去查資料、編輯起稿、校對改錯字、排版產出最終 docx。彼此交接時帶上下文，但又不互相干擾。這是 2026 年 Claude Code 最被低估的功能。

幫我在 .claude/agents/ 建立 4 個 subagent： 1. researcher.md - 角色：嚴謹的資料研究員 - 工具：只能 WebSearch、Read - 風格：列出來源、標註可信度 - 產出：研究筆記 markdown 2. writer.md - 角色：擅長說故事的科普作家 - 工具：Read（讀 researcher 的筆記）、Write - 風格：白話、有比喻、避免術語 - 產出：草稿 markdown 3. editor.md - 角色：嚴格但溫和的文字校對 - 工具：Read、Edit - 任務：抓錯字、邏輯不通的地方 - 限制：禁止改變作者語氣 4. designer.md - 角色：版面設計師 - 工具：呼叫 docx skill - 任務：把最終稿轉成排版精美的 docx 請建立檔案後，示範一次完整流程：寫一篇關於「自家陽台種番茄」的科普文。
為什麼是高階專案 牽涉到 Subagent 設計、工具權限分配、Agent 間的協作流程——這是真正把 Claude Code 從「個人助理」升級成「AI 工作室」的關鍵。學會這個，你就能為任何複雜工作建立專屬的 AI 團隊。

個人作品集網站

零程式基礎也能在喝完一杯咖啡前完成上線

準備好你的個人介紹、過往經歷、3-5 個作品的圖片或描述，丟給 Claude Code，它會自動產生 HTML + CSS 的單頁網站，並可串接 Netlify 一鍵部署上線。看到不滿意的地方？用截圖告訴 Claude「這裡的顏色想改成深綠」，它就會修。

幫我做一個個人作品集網站（單頁式）。 我的背景：[貼上你的簡歷或自介] 重點作品：[列 3 個作品+簡述] 風格：簡潔、現代、配色用米白與墨綠 產出：單一 HTML 檔案，含內嵌 CSS，能直接打開預覽
為什麼適合當第一個專案 你能「看見」AI 的成果（一張網頁），有立即回饋；又能練習「給 Claude 上下文」這個最重要的技能。

把雜亂 CSV 變成主管報告

從「打開檔案頭痛 60 分鐘」變成「丟給 Claude 90 秒」

給 Claude Code 一個亂七八糟的 CSV（多個分頁、欄位不一致、日期格式混亂），請它清理、合併、做樞紐分析，最後產出一份含圖表的 Word 或 PDF 主管報告。整個過程 Claude 會自己寫 Python，你只需要看結果。

幫我整理這個 CSV 檔案：[拖曳檔案] 1. 清理欄位：把日期統一為 YYYY-MM-DD，文字欄去除多餘空白 2. 合併重複客戶資料 3. 依月份做樞紐分析（橫軸=月份、縱軸=產品線、值=營收） 4. 產出 Excel 檔，含一張長條圖 5. 另附一份 Word 摘要，重點寫 3 個我該知道的趨勢
給初學者的小訣竅 不要說「分析這份資料」（太籠統）。要具體說「我想知道哪 3 件事」、「報告要給誰看」——Claude 就會自動挑對的圖表類型與摘要寫法。

個人化待辦與研究助理

把雜亂的待辦清單、文件、會議筆記，變成「會自動分類整理」的個人系統

把你平常的待辦事項、會議記錄、研究筆記丟在一個資料夾，請 Claude Code 幫你建立一套「個人化整理系統」——例如自動把待辦分成「今天必做 / 本週重要 / 在等別人」，自動把研究筆記依主題歸檔，每週五早上自動產生一份「本週進度回顧」。產品經理 Teresa Torres 用這套方法管理她所有的客戶研究與寫作。

幫我設計一個個人任務管理系統，存在這個資料夾。 我的工作型態：[簡述：例如「每天有 3-5 個會議、要追蹤 10 個專案、寫 1-2 篇文章」] 我需要： 1. 一個 todo.md，依「今天/本週/等待中/未來」分類 2. 一個 research/ 資料夾，每篇筆記自動加上主題標籤 3. 每週五自動產生 weekly-review.md，幫我盤點進度 請先問我 3 個問題釐清需求，再開始建立。
為什麼這個有威力 不是用「現成的 App」，而是讓 Claude 為你量身打造——你的系統會跟著你的工作習慣演化，而不是逼你配合別人設計的軟體。

多語言部落格 / 社群貼文工作流

寫一次中文，自動產出英文、日文、IG 短文、LinkedIn 長文四種版本

建立一個資料夾結構：把你的中文草稿丟進 `drafts/`，請 Claude Code 自動翻譯成英文 + 日文，再依不同平台改寫——IG 要 caption 加 hashtag、LinkedIn 要長文加觀點、Twitter 要 280 字內。你還可以給 Claude 你過去的貼文作為「語氣樣本」，它會模仿你的風格。

我要建立內容發布工作流。 資料夾結構： - drafts/ 我的中文草稿 - published/zh、/en、/ja、/ig、/li、/x 各語言/平台的成品 - voice-samples/ 我過去的 5 篇貼文（學我的語氣） 任務：當我把新草稿放進 drafts/，請你： 1. 翻譯成英文與日文（保留專業術語） 2. 改寫成 IG 短文（含 5-7 個 hashtag） 3. 改寫成 LinkedIn 長文（加我的觀點延伸） 4. 改寫成 Twitter 280 字內 所有產出都要模仿 voice-samples/ 的語氣
關鍵心法 讓 Claude「讀你以前的東西」——它模仿你的語氣比你想像中精準。3-5 篇樣本就夠了。

5 中階 程式原型 60 分鐘 5/16

復古 2D 小遊戲（如太空射擊）

用一頓飯的時間，做出一個能玩、能分享的小遊戲

選一個經典遊戲模板（太空射擊、貪食蛇、打磚塊、俄羅斯方塊），請 Claude Code 用 HTML5 Canvas + JavaScript 做出來。每個關卡完成後可以加新功能：「敵人會躲」、「加 boss 戰」、「加音效」、「加排行榜」。是練習「跟 Claude 反覆迭代」的最佳場景。

幫我做一個復古 2D 太空射擊遊戲。 技術：單一 HTML 檔，用 Canvas + JavaScript（不用框架） 基本功能： - 玩家飛船（方向鍵移動、空白鍵射擊） - 敵人從上方下來，撞到玩家就 Game Over - 計分系統、按 R 重來 - 視覺風格：8-bit 復古配色（深紫底、亮綠/粉紅雷射） 做完後告訴我可以加哪 3 個進階功能，我選一個再實作。
遊戲為什麼是好的練習 回饋立即（能不能動一眼看出來）、容易增量加功能、寫程式時最不會無聊。完成後可以丟到 GitHub Pages 分享給朋友玩。
